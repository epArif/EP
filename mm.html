🌐 ভাষা

অ্যাপের লেখা বাংলা, ইংরেজি, নাকি দুটোই একসাথে দেখতে চাও বেছে নাও।

☁️ Cloud Sync (getPantry) কনফিগার করা হয়নি

getpantry.cloud থেকে ফ্রি একটা Pantry বানিয়ে তার ID এখানে বসাও — তাহলে তোমার progress অন্য ডিভাইস থেকেও sync হবে।

🔥 Cloud Sync (Firebase Realtime Database) কনফিগার করা হয়নি

console.firebase.google.com এ প্রজেক্ট বানাও (অথবা তোমার আগের ExPo Vault প্রজেক্টটাই ব্যবহার করো), Realtime Database চালু করো, তারপর ডেটাবেজের URL (যেমন https://your-project-default-rtdb.firebaseio.com) এখানে বসাও। Rules টেস্ট মোডে (allow read/write: true) থাকলে Auth ফাঁকা রাখতে পারো। Sync ID তুমি নিজে যা ইচ্ছা লিখতে পারো — একই URL + Sync ID যেই ডিভাইসে বসাবে, সব জায়গায় progress sync হবে।

🔄 Auto-Backup

চালু থাকলে, উপরের Pantry ID / Firebase URL যেটাই বসানো থাকুক (Firebase-কে আগে চেষ্টা করবে, না থাকলে Pantry), তোমার প্রতিটা checkbox-click বা শব্দ যোগ/এডিট করার কিছুক্ষণ পর নিজে থেকেই চুপচাপ cloud-এ backup হয়ে যাবে — আলাদা করে Upload বাটনে চাপতে হবে না। Backup শুধু তোমার progress (কোনটা পড়া হয়েছে, override) পাঠায় — কোনো API key/ID কখনো cloud-এ যায় না।

🧠 Gemini API (Flashcard AI-এর জন্য) 0/10 key দেওয়া আছে

নিচে ৩টা মডেলের নাম দাও (latest ভার্সন যেটা এখন চলছে — flash/pro/flash-lite) এবং ১০টা পর্যন্ত API key। প্রতিটা key দিয়ে ক্রমান্বয়ে ৩টা মডেল try হবে (কোনো wait ছাড়াই); একটা key-র সব মডেল fail হলে পরের key দিয়ে আবার ৩টা মডেল try হবে। সব key + সব মডেল একবার করে fail হয়ে গেলে rate-limit এড়াতে ১ মিনিট wait করে আবার প্রথম থেকে try করবে। প্রতিটা শব্দের AI উত্তর একবার আনলে save হয়ে থাকবে (ফোনেই), পরে আবার একই শব্দ দেখলে offline-এও কাজ করবে আর নতুন করে token খরচ হবে না। এই key গুলো শুধু এই ডিভাইসের ব্রাউজারে (localStorage) সংরক্ষিত থাকে — কোনো sync/backup/cloud-এ কখনো পাঠানো হয় না, এমনকি Auto-Backup চালু থাকলেও না।

💡 MCQ ব্যাখ্যা Backfill

আগে যেসব MCQ শব্দের distractor জেনারেট হয়ে গেছে কিন্তু ব্যাখ্যা (explanation) নেই — এই বাটনে চাপলে শুধু ওগুলোর জন্যই নতুন করে AI থেকে ব্যাখ্যাসহ regenerate হবে। উপরের Gemini key/model লাগবে।

⚠️ রিসেট

এতে তোমার সব পড়া/মুখস্থ progress (কোনটা পড়া হয়েছে, override, MCQ practice history, ভুল হওয়ার হিসাব, দৈনিক রুটিন-চেকলিস্ট) সম্পূর্ণ মুছে যাবে এবং আজকের তারিখ থেকে সব প্রথম থেকে শুরু হবে। তোমার নিজের যোগ করা শব্দ, শব্দের ক্রম, Settings/API key — এগুলো অক্ষত থাকবে।
