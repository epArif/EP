⚠ সব ডাটা রিসেট

সাবধান, এটা আর ফেরানো যাবে না।
এই ডিভাইস থেকে সব ক্যাশ এন্ট্রি, সেভিংস, প্ল্যান, সেটিংস, PIN আর Sync/Gmail কানেকশন মুছে যাবে। তোমার Google Sheet আর Gmail-এ থাকা backup মুছবে না। আগে Backup নামিয়ে বা Gmail-এ পাঠিয়ে রাখো।

Gmail Backup

Sync-এর Code.gs (Gmail সহ নতুন ভার্সন) deploy করা থাকলে URL আর token নিজেই বসে যাবে। Backup পাঠালে তোমার নিজের Gmail-এ JSON ফাইলসহ মেইল যাবে, আর Restore দিলে সবচেয়ে নতুন backup থেকে ডাটা ফিরে আসবে (merge)।

Google Sheet Sync

Code.gs deploy করে Web app URL আর token এখানে দাও। দ্বিতীয় ডিভাইসে আগে কোনো এন্ট্রি না রেখে sync করো, নইলে একই হিসাব দুইবার ঢুকতে পারে।
